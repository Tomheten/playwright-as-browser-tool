1. Setup: 
   - Update Git
   - If need auto-formatting on a commit then should put property `hooksPath = .git-hooks` to [git-config](.git/config) into `[core]`
   - set Node.js in 24 version
   - npm i
   - Default formatting - dprint. Need to set globally - `npm i -g dprint`. [install-doc](https://dprint.dev/install/)
